
Heritage House – Project Showcase

# Overview

The application allows users to:

1 View existing projects
2 Add new projects
3 Search for projects by name
4 Display project titles and descriptions
5 Interact with a simple and user-friendly interface

# Features

## Project Listing

The application displays a list of projects with their:

1 Project name
2 Project description

## Add a Project

Users can add a new project by entering:

1 Project Name
2 Project Description

## Search Projects

The application includes a search field that allows users to search for projects by their name.

The project list updates dynamically as the user types.

# Getting Started
Prerequisites

Make sure you have the following installed:

1 Node.js
2 npm
3 Git

# Installation

Clone the project repository and navigate to the project directory

```bash
 git clone
    cd heritage-house
```
# Running the Application
Start the development server

```bash
npm run dev 
```
