
Heritage House – Project Showcase

# Overview
Heritage House – Project Showcase is a React web application that allows users to browse, search, and add projects through a simple and user-friendly interface.

The application demonstrates core React concepts including components, props, state management, event handling, controlled forms, and dynamic rendering.

# Features
# Project Listing

The application displays a list of projects with:

1. Project name
2. Project description

The initial projects include:

1. The Heritage Villa – A beautifully designed residential villa combining modern comfort with traditional architectural elements.
2. Mara Lodge – A stylish hospitality project inspired by the natural beauty and cultural heritage of the Maasai Mara.

# Features


## Add a Project

Users can add a new project by entering:

1 Project Name
2 Project Description

## Search Projects

The application includes a search field that allows users to search for projects by their name.

The project list updates dynamically as the user types.

# User-Friendly Interface

The application provides a simple interface that makes it easy to:

1. View projects
2. Add new projects
3. Search for projects
4. Read project descriptions

Fork and Clone the project repository and navigate to the project directory

```bash
 git clone
    cd heritage-house
```
# Running the Application
Start the development server

```bash
npm run dev 
```

# How to Use
## View Projects

When the application loads, the existing Heritage House projects are displayed on the page.

1. Add a Project
2. Enter a project name.
3. Enter the project description.
4. Click Add Project.
5. The new project will appear in the project list.

## Search for a Project
1. Click inside the Search Projects field.
2. Enter the name or part of the name of a project.
3. The project list will automatically filter based on the search term.
